# Optional adaptive classifier

Three complete recipes implement bounded classification, caller-assisted category
proposals and independent held-out evaluation. The installed MCP guide provides
these same files without needing a source checkout.

- [Classify](classify/process.json): Jev plus opt-in collection of Other cases.
- [Propose](propose/process.json): durable caller review and add-only candidate.
- [Evaluate](evaluate/process.json): paired Jev predictions and deterministic gate.
- [Connection proposal](connection.json): protected, unapproved template; no secret.

Follow the [agent guide](../../integrations/knowledge/classifier-learning.md) for
exact inputs, pagination, spending limits and reviewed registration. The [user
runbook](../../docs/runbooks/classifier-learning.md) explains the optional flow.
No sample is an account grant, scheduled job or live-provider quality result.
