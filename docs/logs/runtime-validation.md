- `python3 examples/local-review/demo.py --apr <binary> --state-dir <temporary-directory> --demo-dir <private-directory> start`, then `submit --approved true` and `export`, completes the manual demo. The exported ZIP and repeated receipt were verified.

Build outputs were moved to a temporary directory after macOS blocked reads of Cargo fingerprint files under the Documents checkout. This changed no source or runtime state behavior; the reproducible commands can use `CARGO_TARGET_DIR` outside a synced directory.

### Build versus extend

Keep the small Rust runtime for the scoped authority, transactional receipts, and durable caller handoffs required here. Reuse commodity libraries instead of implementing SQLite, JSON Schema, hashing, ZIP, or CLI parsing. Artifact publication adapts Lobster's MIT atomic exclusive-write sequence, adding descriptor-anchored paths, content verification, and retention of published objects after a late sync error. [Third-party notices](../../THIRD_PARTY_NOTICES.md) record the exact source and license.

Lobster's TypeScript engine and Cloudflare's JavaScript execution environment are not interchangeable with APR's SQLite transaction and local credential boundaries. Their whole runtimes were not embedded. Windmill backend code was not copied because its mixed licensing and server architecture do not fit this slice. The official Rust MCP SDK is the selected reuse candidate for M1; it is not an M0 dependency.

### Boundaries of this evidence

These tests cover process termination, not physical power loss, full-disk behavior, filesystem corruption recovery, or backup/restore. M0 serializes executors with an OS file lock; it does not test independently running stale workers. Metadata is declared, not inferred from file contents. Step time limits are checked before result commit without preempting synchronous I/O. No daemon, project/assignment scope enforcement, actual client journey, paid provider, token savings, sandbox, installer, or desktop runtime has been established by M0.
